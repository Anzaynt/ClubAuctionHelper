# 仓库生成规则确认清单

这份清单用于把游戏的“仓库如何生成”转换成求解器可执行的规则。请按每项标记为“已确认 / 未知 / 不适用”，并写下你观察到的例外。

## 已确认的求解口径

- 仓库视为可重复的藏品多重集合；不假设固定总件数、总格数或单品重复上限。
- 同一属性的随机情报不会再次指向同一件藏品；不同属性仍可能指向该藏品。
- 求解器输出满足当前信息的**保守收益下限**；若没有足以限制总量的线索，上界显示为不封顶，而不制造虚假的候选枚举。

## 一、每局仓库的基础构成（优先确认）

### 1. 仓库数量与容量

- 每局仓库中的藏品数量是否固定？如果固定，是多少件？不固定
- 所有藏品占用的总格数是否固定？如果固定，是多少格？不固定
- 仓库是否有二维摆放限制（例如格子必须能排进固定长宽的仓库），还是只关心总格数？只关心总格数
- 同一局中，是否可能出现“没有任何藏品”或只有一件藏品的特殊情况？不可能

### 2. 藏品抽取范围

- 每局藏品是否只会从 `data/藏品图鉴汇总.csv` 中抽取？是否有活动限定、未收录或禁用藏品？只会从 `data/藏品图鉴汇总.csv` 中抽取。
- 游戏是否会根据玩家等级、模式、地图、赛季或房间类型改变可出现的藏品池？会，但不考虑。
- 是否有“本局必定至少出现某品类 / 某品质”的保底规则？否
- 是否有“某些藏品不能与某些藏品同局出现”的互斥规则？否

### 3. 重复规则（非常关键）

- 同一个**具体藏品**是否可以在同一仓库中重复出现？可以
- 若可以重复：同一种藏品单局最多可出现几件？不知道
- 同一名称、不同品质/价值/轮廓的条目，在游戏里是否视为不同藏品？是
- 同一品类是否允许重复？同一品质是否允许重复？允许

## 二、品质、品类和价值的生成规则（优先确认）

### 4. 品质分布

- 白、绿、蓝、紫、橙、红六种品质是否全部可能出现？是否还有未列出的品质？有可能全部出现。没有未列出品质
- 每种品质在一局中的数量是否有上下限？例如红品最多 1 件、紫品最多 3 件。没有上下限。
- 是否存在品质配额或概率规则，例如“至少 1 件紫品以上”“红品出现时橙品数量受限”？没有限制
- “最高品质”是按白 < 绿 < 蓝 < 紫 < 橙 < 红的固定顺序判断吗？是的
- 多件并列最高品质时，这些藏品是否都属于“最高品质藏品”？是的

### 5. 品类分布

- 图鉴中的品类是否完整且固定？当前 CSV 的品类是否与游戏内分类完全一致？是的
- 每种品类单局是否有数量上限、下限或保底？无限制
- 是否存在品类组合规则，例如某两类不能同局、或某类只在特定品质出现？没有

### 6. 价值规则

- CSV 中的“价值”是否就是游戏线索和拍卖所使用的基础价值？是否会受局内系数、事件、玩家技能影响？价值不会变
- 同一藏品在不同局的价值是否恒定？是的
- 游戏显示的“总价值”“平均价值”是否精确到整数？平均值是否会四舍五入、向下取整或保留小数？这两个精确到整数，向下取整。平均格数会保留1位小数，也向下取整。
- 若平均值不能整除，界面实际会显示什么格式？请给一个实测例子。无关

## 三、轮廓与格数规则（优先确认）

### 7. 轮廓与占格

- 一个藏品的“轮廓”和“占用格数”是否永远由图鉴条目唯一决定？是的
- `1×2` 与 `2×1`、`2×3` 与 `3×2` 是否在游戏内视为不同轮廓？是的，但占位相同。
- 游戏是否允许旋转藏品？若允许，线索显示的是原始轮廓还是旋转后轮廓？不允许
- “格子占用最多”只比较占格数量，还是会额外比较长宽？只比较数量
- 多件并列最大占格时，它们是否都属于“占用格子最多的藏品”？是的

### 8. 摆放约束（若游戏实际会摆盘）

- 藏品是否必须无重叠地放入固定尺寸的二维仓库？仓库尺寸是多少？无关
- 是否允许旋转？是否允许留空格？不允许旋转，允许空格
- 线索中的总格数只是所有物品面积之和，还是受实际可摆放性限制？所有物品面积之和

> 若游戏没有“摆盘失败”的机制，此节可标记为不适用。第一版求解器只需使用总格数。

## 四、情报文本的精确定义（优先确认）

这里决定每一条情报应转换为“等式、范围”还是“抽样观察”。建议每种句式至少截图或记录两次。

### 9. “所有 / 指定品质 / 指定品类”类

- “所有藏品”是否确实覆盖仓库中的每一件藏品？是的
- “某个指定品质的藏品”是否包含该品质的全部藏品？是的
- “某个指定品类的所有藏品”是否包含该品类的全部藏品？是的
- 当目标集合为空时，游戏是否会提供这类情报？若提供，显示为 `0`、空白还是不出现？0

### 10. “随机 X 件”类

- X 是由游戏固定给出，还是玩家可选？可取哪些值？玩家可选。取值无关。
- 同一条情报里的 X 件是否保证互不重复？是
- 多次获得相同句式时，后一次是否只避开**之前已展示的具体藏品**，还是只避开相同的信息值？避开相同的信息值
- “不指向相同藏品”的范围是：
  - 仅同一句式内；
  - 同一信息类型内；
  - 同一局所有情报内；
  - 还是只要该藏品任一属性已被看到，就不再出现？只要该藏品任一属性已被看到，就不再出现
- 如果剩余可抽取目标少于 X 件，游戏会怎样处理？不会少于

### 11. “随机 1 个最高品质 / 最大占格”类

- 抽样范围是否为所有并列最高品质（或并列最大占格）的藏品？是的
- 若最高品质 / 最大占格只有一件，重复获取同类情报是否会：不再出现、改指向其他范围，还是允许重复？会指向次一品质/次最大占格
- 该类“随机 1 个”与普通“随机 X 件”是否共享不重复记录？是
- 看到轮廓后，再获取该目标的价值或完整信息，是否可能指向同一件藏品？如果只有轮廓，其他信息是有可能指向该藏品的

### 12. “完整信息”类

- 完整信息具体包含哪些字段：名称、轮廓、价值、品质、品类之外是否还有字段？否
- 获得完整信息后，该藏品是否自动视为已知，并从所有后续随机情报的候选中排除？是的
- 多次“随机 X 个完整信息”之间是否保证不重复？是的
- “所有藏品的完整信息”是否会一次性揭示仓库全部条目，含重复项？是的

## 五、数值计算与显示规则（优先确认）

### 13. 求和与平均

- 指定品质总价值、所有总价值、总格数、数量，是否总是精确整数？是的
- 平均格数、平均价值的分母是目标集合实际数量吗？是的
- 平均数显示精度、舍入规则是什么？例如 `6.5`、`6.50`、`7` 分别可能如何出现？
- 游戏是否用“约等于”或区间来显示某些平均值？否

### 14. “最大”与并列

- 最大品质、最大占格的比较是否允许并列？（通常应允许。）是
- 并列情况下，情报的措辞是否会变化？否
- 一个藏品同时满足“最高品质”和“最大占格”时，两个随机情报是否可以都指向它？是

## 六、模式与时间相关规则（建议确认）

- 5 回合只影响可获得的情报次数，还是会在回合之间新增、替换、移除仓库藏品？藏品不会变化
- 不同玩家得到的情报是否都指向同一个公共仓库？是
- 玩家之间的信息是否会互相影响随机不重复规则？否
- 是否存在道具、事件、角色能力会修改藏品池、价值、品质、格数或情报文本？否
- 是否有不同玩法模式，且它们使用不同仓库生成规则？否

## 七、建议你优先回答的最小集合

只要先确认下面 10 项，就可以开始做第一版“候选池筛选 + 冲突检测”：

1. 每局总藏品数量、总格数是否固定，分别是多少？
2. 同一具体藏品能否同局重复？
3. CSV 是否覆盖当前模式的全部可出现藏品？
4. 品质是否存在每局上限、下限或保底？
5. 是否有品类上限、下限或互斥组合？
6. 轮廓是否可旋转，旋转后是否仍算同一个轮廓？
7. 平均价值、平均格数的精度和舍入方式？
8. 同类随机情报的“不重复”究竟按具体藏品、信息类型，还是全局生效？
9. 完整信息是否会让该藏品退出后续所有随机抽取？
10. 回合间仓库是否完全不变？
