# ClubAuctionHelper

本地运行、桌面优先的拍卖仓库情报录入与推理助手。

## 启动方式

不要直接双击打开 `index.html`。浏览器会把它作为 `file://` 页面打开，出于安全限制无法读取 `data/藏品图鉴汇总.csv`。

最方便的方式是双击项目根目录的 `启动本地预览.cmd`，再在浏览器打开 `http://localhost:5173`。

也可以在项目根目录执行：

在项目根目录执行：

```cmd
python -m http.server 5173
```

然后在浏览器打开 `http://localhost:5173`。

当前已实现：

- 六类情报的两层选择：轮廓、品质、价值、格数、数量、完整信息；
- 23 条默认情报模板；
- 根据模板自动呈现条件和结果输入；
- 随机 X 件结果的动态输入行；
- 从 `data/藏品图鉴汇总.csv` 载入名称列表；
- 浏览器本地保存、撤销与清空本局记录。
- 保守价值边界：全局总价值/完整仓库可精确确定；总格数、总数量和指定品质统计可给出保证成立的价值下限；基础冲突检测。
