# ClubAuctionHelper

本地运行、桌面优先的拍卖仓库情报录入与推理助手。

## 启动方式

不要直接双击打开 `index.html`。浏览器会把它作为 `file://` 页面打开，出于安全限制无法读取 `data/藏品图鉴汇总.csv`。

最方便的方式是双击项目根目录的 `启动本地预览.cmd`，再在浏览器打开 `http://localhost:5173`。

也可以在项目根目录执行：

在项目根目录执行：

```cmd
python -m http.server 5173
```

然后在浏览器打开 `http://localhost:5173`。

当前已实现：

- 六类情报的两层选择：轮廓、品质、价值、格数、数量、完整信息；
- 27 条默认情报模板；
- 根据模板自动呈现条件和结果输入；
- 左侧信息大类和情报句式支持鼠标悬停即选择，触屏与点击操作继续保留；
- 每类情报统一按“全体/汇总 → 指定条件 → 极值对象 → 随机样本”排列；
- 随机 X 件结果的动态输入行；
- 从 `data/藏品图鉴汇总.csv` 载入名称列表；
- 浏览器本地保存、撤销与清空本局记录。
- 红、橙、紫品质的单件价值反查：唯一命中时直接显示藏品，一对多时列出全部候选；
- 同品质联合推断：联立总价值、数量、总格数、平均格数、全部轮廓和已知单件属性，枚举可行组合并标出必然包含项；
- 将图鉴无法覆盖的实际情报标记为数据库差异，不再误报为用户情报冲突；
- 数量、总格数、平均格数和平均价值之间的自动换算，以及基础冲突检测。

求解结果聚焦高品质藏品，不再计算仓库最低总价值。
